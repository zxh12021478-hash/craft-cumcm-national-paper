# APMCM：让创新、推荐与摘要服从证据

这轮改进针对两个实际问题：识别出错误以后，交接仍可能安排过量补算；摘要虽然数字正确，却仍像压缩的审查报告。制作测试使用豆包，未调用付费 Modex。国赛核心与比赛流程保持原样。

## 已落实的修改

- **分别验证三类主张**：指定实例上的方案比较、固定骨干/参数下的模块贡献、向未见场景推广，各自选择所需证据。不能把全因子消融、重新调参和留出验证设为每题统一流程。
- **补算有下一步和停止条件**：先核实实际缺失接口及硬可行性；关键检查失败就停止升级，保留已有效的方案。某个算法或候选失败，不构成原问题不可行的证明，不能据此放松题目约束。
- **摘要陈述修复后的结果**：保留直接答案、决定推荐的比较和必要边界；纠错历史与未来实验放审查记录。无必要不把同一比较展开为更多日差额、人数和分组小计；需要的新结果先进入正文。
- **限制统计外推**：置信区间为正和评估集零失败，都不足以单独证明域外有效或未来约束必然满足。区间/检验取决于估计对象与抽样结构，有限描述结论无需强加显著性门槛。

主要变更在 [入口](../skills/craft-apmcm-paper/SKILL.md)、[路线反驳与补算](../skills/craft-apmcm-paper/references/route-challenge.md)、[英文审查](../skills/craft-apmcm-paper/references/english-audit.md)和[摘要协议](../skills/craft-apmcm-paper/references/abstract-priority.md)，没有增加运行依赖或默认加载全部材料。

## 验证与限度

新合成夹具刻意同时包含错误材料与有效对照。第一例所谓20%降本仅来自有利子集：候选还在4/20场景违反硬约束，即便在共同完成的16场景上也比参考贵5%；另一例5%降本、服务提升2个百分点的有限描述则应保留。第三例是给定有限模型的完整枚举，A+B成本12达到独立解析下界，无需用留出数据证明这个数学结论。

实际审查产物既有正确发现，也有新的错误：消融过度、错误归因、过度外推和摘要重复没有因自报“通过”而被接受。原始输入、原始失败、后续试用与主代理修复分别保留，详见[开发验收](../evaluations/apmcm/innovation-evidence/assessment.md)。

40项APMCM脚本测试及技能结构检查通过。原国赛核心未修改，本轮未重跑其历史102项测试。这些制作试验不是完整官方赛题表现、真实Modex兼容性、实测物理验证或获奖概率的证据；没有实际额度计量，不报告节省百分比。
