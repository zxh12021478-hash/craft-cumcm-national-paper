# 新手册索引与摘要目标核对

用户提供的手册共441个物理页，目录收录2023—2025年的11篇英文赛优秀论文。已阅读目录、前置报名/集体报名/章程规则的9页图像，并记录各案例的定位；没有把441页标成全文读完。目录、指纹、具体阅读范围和限制见[手册索引](../evaluations/apmcm/handbook-index-20261031.json)。原PDF不重新发布。

手册前置文件落款2026年8月，不能覆盖[10月20日官网参赛规则](https://www.apmcm.org/detail/2513)。中英文报名页的队伍人数和午夜截止表述不同，旧集体报名页的承诺书格式/签署说明也不能替代后发规则。现有已核字段保持，AI具体许可、完整英文模板、页数上限和完整页面顺序没有据此转成已确认。高校页面有同名附件，但下载超时，未证明其与用户文件逐字节等同；官网章程菜单仍显示2020版，也不能用该页面为手册的2026修订背书。

案例的队号、奖级和最终提交版本需分别核验。“优秀论文”标签不等于每项结果正确或文件完整：2024B在手册中有28页，页眉从1/72到28/72；2024D有76页而页眉分母101；2023B的23页仍带44的分母。最后可见页是参考文献，也不能据此推断不存在不可见附录。只学习实际可见内容，不把这些案例当作完整实现/全文复现证据。新的2025案例已暴露少量开头提示，未来演练需记录，不能再称零知识或未看同题方案。

## 前一轮摘要检查实际发现的缺口

冻结的自制2024B演练与本次手册案例是不同作品。其正文/代码分别用温度、粒子、湿度指标求解Q1–Q3，只有Q4使用等权综合目标；制作期摘要却把全部问题写成统一加权目标。另一个错误是把同风量比较写成外形贡献：输出记录显示两者同为塔形且风量相同，仅摆放位置、出风角度改变。

因此只保留两处短引用修改：摘要选材对应每问实际目标；英文审查核对独立单项目标与综合权重，并按实际变化字段限定比较含义。对照配置和算术有[可复算记录](../evaluations/apmcm/summary-target-scope/check.py)。既有384项结果算术、5种设计的小范围原实现重放及数组末值检查支持这项修正；它们不是实物验证，也不代表重跑了完整搜索。

原始摘要、正文和结果未覆盖。后续同会话定向修订没有取得可核产物，不计为接收者行为测试通过；完整长文的正向摘要迁移与新PDF验收仍未完成。该限制与本次已确认的目标/对照语义修正分开记录。没有调用付费Modex，没有修改国赛核心。
