# Method references and upstream notices

The APMCM additions are selectively adapted and independently rewritten for the user's Modex handoff/audit workflow. Entire upstream skill bundles were not installed. Source snapshots and adoption decisions are recorded in [the learning report](github-learning-20261018.md). No statements here establish upstream performance or prize quality.

The linear checker is a new standard-library implementation informed by the independent-verification interface documented in MathModel-Skill; it is not the upstream NumPy function. MIT notices for the referenced licensed projects are retained below. The pymoo skill's own frontmatter says Apache-2.0; only general optimization methods are summarized, with no pymoo code or skill text copied. The repositories with no detected top-level license were read as public research references, without copying their code or prose into the skill.
