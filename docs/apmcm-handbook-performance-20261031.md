# 从手册案例补强“保持任务的优化”

本轮将用户手册中的一个可见建模缺口转成四处支持引用的改进，没有增加比赛表单、外部调用或交接前完整求解要求。国赛版不变。原手册不上传，公开记录仅含定位、独立分析和少量核查数值。

## 来源与实际发现

阅读范围是2025 A案例的完整摘要、物理第87–94页能耗章节，以及第19–21页相关原题；题面、缩放公式和结果表共6页另作视觉核对。其余页面虽提取文字，但没有标成精读或全文验证。该队确切奖级未核；29个物理页末页仍带Page27of46，完整版本不明。

案例把轨迹整体延长1.5倍，报告各问节能33.3%。原题的10米路程、2米/秒平均速度对应5秒，原画圆周期是4秒。按可见变换，前者会成为7.5秒、后者成为6秒。Q4的“不影响性能”是否允许改变这些条件需要明确解释；几何形状相似不够支持原任务性能保持。另见Q4输入把Q3轨迹写成10秒，与原题4秒不一致。

能源检查也需按口径进行。在表列电机全程开启、额外电功率非负的条件下，延时后仅基础耗能下界即为6J和21J，高于案例所报2.67J和9.33J。没有取得作者轨迹和代码，因此只记录条件性冲突；不能推断其内部具体采用了何种积分、符号、启停或回收实现。

## 改了什么

- 路线选择：将“不影响性能”变成原题不变量，复用现有交接包约束/检查栏，交代可改变的自由度。运动题可探索固定末端任务与时长的冗余关节配置/协同；这仍是待验证路线，不声称完成机器人求解。
- 物理核查：缩放后重新计算速度、加速度和积分时域，明确机械功与电池耗能、基础负载与再生制动口径，先用下界或短轨迹积分判断是否值得优化。
- 英文摘要：性能保持尚未闭合的收益不能直接入选；题目允许的延时权衡需保留延时条件。
- 案例学习：保留跨问复用轨迹的接口思路，拒绝直接照搬其节能结论和“普遍有效”解释。

## 验证及边界

[局部脚本](../evaluations/apmcm/handbook-performance/check.py)实际执行通过：[结果](../evaluations/apmcm/handbook-performance/check-results.json)、[评估](../evaluations/apmcm/handbook-performance/assessment.json)。它核对速度、周期与条件基础耗能下界；再用自造的静止起止轨迹，将独立数值积分与解析能量对照。高基础负载时放慢反而多耗能，低基础负载时放慢可以省能，防止把修正过度泛化成“永不允许放慢”。有符号机械功在该闭合轨迹中接近零，也不等于电池零耗能。
