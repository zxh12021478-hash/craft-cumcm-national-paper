# 摘要：先选内容，再完成实际删减编辑

此前制作测试中，执行器虽然知道“摘要应简洁”，仍把输入参数、整张可行解表、推导和纠错说明搬进摘要。第一次增加选择说明后仍有失败，不能因字数下降就算解决。

本轮把流程改为：完整论文与结果核对 → 选择必答结果、机制、决定性证据和必要边界 → 候选摘要 → 删除/合并非必需信息 → 核对答案及事实。最后一步是当前写作轮次内的编辑操作，不要求比赛时新增外部 agent 或模型调用；已有正确但冗长的 Modex 摘要可直接进入该编辑操作。

具体改动在[摘要协议](../skills/craft-apmcm-paper/references/abstract-priority.md)：区分事实核查记录与摘要内容；明确“报告完整枚举的结论”不等于抄全部可行解证明；给出选材和完整短示例；若仍复述非必答的整组输入/候选/淘汰原因，不能仅在 note 声称已删表，须实际回写。没有统一词数或强制段数，也不允许为变短删掉一个必答问、条件、单位或失败边界。

## 实际开发结果

| 完整短稿 | 旧版输出 | 编辑后输出 | 主要保留内容 |
|---|---:|---:|---|
| 配送选择 F | 210词 | 148词 | 两场景的选择、成本对照、硬约束优先及切换原因 |
| 参数识别 G | 229词 | 173词 | 瞬态只识别比值、联合实验识别参数、3小时要求不满足 |
| 确定性模块 C | 178词 | 108词 | 最优解/成本、两种故障剩余供给、比较及证明范围 |
| 未知权重/扰动 H | 无旧版对照 | 224→197词 | 名义分界、并列、弱保证区间和中间条件答案 |

词数按去标题后的空白分词计，公式也影响计数。F/G在首轮为新材料，随后用于反馈修订回归；C是已知回归且示例与其同源；H只在最终候选阶段加入，没有旧版配对。不能把这个表当成普遍效果、官方摘要长度、奖项质量或Codex额度节省。

只读摘要的独立接收者恢复了四稿共十个必答组。之后只明确两处英文限定：误差模型是“未提供”，可能并列的边界是w=1/2或5/6；增量回读确认答案未变、歧义消除。为保留这两处必要精度，最终采纳稿G为174词、H为202词，F/C不变；没有为字数更少而保留歧义。

豆包只在制作测试中承担产出、编辑和只读摘要的接收者；主代理用原题、完整正文、机器结果与独立算术/解析检查核真。初版失败、实际编辑前后产物、选材记录与读者复核均分别留档，见[完整验收](../evaluations/apmcm/summary-selection/assessment.md)。没有调用付费Modex。40项既有APMCM脚本测试和技能结构检查通过；原国赛核心未改。
