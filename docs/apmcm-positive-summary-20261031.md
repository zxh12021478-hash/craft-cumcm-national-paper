# 长论文摘要修订：完成一例有限范围验收

本轮完成自制2024 B历史演练的英文Summary与一处正文修订，并验收新PDF。这是既有24分区、384候选版本的审查修订，和用户手册中的2024 B优秀案例是不同作品；后续有限体积版本的数字没有混入。

## 原始失败与修复

制作期同一豆包会话曾生成543词候选，数字大多能找到来源，但仍有实质错误：将前三问独立最小化的目标混成第四问综合权重；同风量对照改变摆放和角度，却归因于外壳；机制中的“geometry-linked filtration”范围含混，容易与固定滤效假设混淆；原稿后文也注明滤效固定。本轮明确外形影响的是输运、风阻和蒸发容量。选材记录另有上一案例公式编号污染。原始候选和审查记录保留，不能因本轮修复就把原输出改记为通过；此前指令化v2未取得产物，也不计成功。

Codex直接修订既有初稿：[本轮Summary](../evaluations/apmcm/positive-summary/summary.md)。四问的外形、尺寸、出口差别和目标保持独立，共同摆放与风量只说一次；保留双基线、分季能耗、湿度未达标及数值偏差。删除重复的输入参数、整组末值和候选明细。正文仅改同风量比较的归因一句，模型、程序、原始结果和五张图不变。最终314词只记录实际产物，不作为通用配额或额度节省依据。

Skill只补一条有实际失败支持的选材条件：机制须对应实现真正改变的量，固定效率不能写成已优化效率。无需增加表单、模型调用或每次全量求解。

## 实际验收

- [核查脚本](../evaluations/apmcm/positive-summary/check_claims.py)对照冻结结果，实际检查17个映射数值、共享配置、两种收益口径和混合参数重排范围。[结果](../evaluations/apmcm/positive-summary/check-results.json)通过；数字通过不自动证明英文语义，语义审查另记于[评估](../evaluations/apmcm/positive-summary/assessment.json)。
- 新PDF仍为16页，第1页摘要和第10页正文更改。两页直接视觉检查，文字、图、图注及页码正常。其余14页的解码内容流与同一渲染器生成的PNG哈希均相同，复用原有全文视觉证据。
- 首次构建后的短语断言因PDF换行失败；修正检查器的空白归一化后重跑通过，原失败单列保留。这不是模型错误或新科学证据。
- 相关输入指纹与冻结清单一致。复用原有完整稿/程序审查、实际求解复现、384项指标核对和5设计重放，不再跑完整搜索。生产脚本、资产、测试未改，既有40项测试记录复用；Skill结构和安装一致性另验。

这完成的是一份有真实程序输出的长稿摘要修订及受影响页面验收。它是Codex直接修订、已暴露材料上的回归，未证明新的独立接收者迁移效果或实际Modex兼容性；没有调用付费Modex。本模型仍缺实测标定、制造装配及部分物理机制，不因摘要更准确就成为最高奖水平或可直接生产的方案。本届模板/AI等未知项保持原状。国赛版、私人提交及手册原文件均未改或公开。
