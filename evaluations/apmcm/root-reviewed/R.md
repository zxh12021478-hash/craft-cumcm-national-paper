## 1. Q1：名义可排除方案 + 硬预算（cost 单位：百万元人民币）
- 原始指标（cost 百万元, benefit 无量纲, emissions 吨/年）：A(8,70,6)、B(10,80,7)、C(12,85,5)、D(11,75,8)。
- **名义上 D 被 B 支配**（cost 10<11、benefit 80>75、em 7<8）；A、B、C 互非支配；预算 12 下名义均可行，C 恰好贴线（余量 0）。
- ±5% 扰动后不能固定剔除 D：20000 次均匀独立扰动中 D 仍恰被 B 支配的采样频率 0.8800，**0.1200 时完整支配者集合不再恰为 {B}，这不是 B 支配消失频率，也不是 D 成为第一的频率**；C 成本超 12 的采样频率 0.5012（与解析一致：12×U[.95,1.05] 超 12 概率为 0.5）。可行角点反例：B=(10.5,76,7.35)、D=(10.45,78.75,7.6)，其余方案取名义值，均在 ±5% 内，此时 D 非支配。结论：Q1 在名义值下排除 D，但在 ±5% 不确定性下支配并非恒成立；C 的预算可行性同样不稳健。

## 2. Q2：精确权重区域（min-max 归一化，分数推导；w_c+w_b+w_e=1）
归一化得分：A(1,0,2/3)、B(1/2,2/3,1/3)、C(0,1,1)、D(1/4,1/3,0)。两两胜出的**精确不等式**（由代码 Fraction 导出并枚举核验）：
- C≥A ⇔ 6w_c+2w_e ≤ 3；C≥B ⇔ 5w_c−2w_e ≤ 2；
- B≥A ⇔ 7w_c+6w_e ≤ 4；
- B≥D ⇔ w_c/12 ≤ 1/3（w_c≤1 恒成立）；C≥D ⇔ 11w_c/12−w_e/3 ≤ 2/3（非全单纯形恒成立；例如 w_c=1 时 C<D）。但若 C≥B，则由 B>D 可推出 C>D；
- A≥D ⇔ 13w_c+12w_e ≥ 4。
- 枚举（STEP=20 → **实际步长 0.050，231 个格点，标签由参数生成**）：独占区域占比 C 0.5887、A 0.3593、B 0.0260、D 0，平手 6 点。
- 推荐：无偏好时等权仅是**参照约定、不是真实偏好**；等权参照 C 胜（0.6667>A 0.5556>B 0.5>D 0.1944）。向量归一化等权参照下 A 0.5364>C 0.5295，第一名单纯形内随归一化翻转。条件推荐（单纯形内，边界允许并列）：C 为第一须同时满足 6w_c+2w_e≤3、5w_c−2w_e≤2；B 为第一须同时满足 7w_c+6w_e≤4、5w_c−2w_e≥2；A 为第一须同时满足 7w_c+6w_e≥4、6w_c+2w_e≥3。不据未知权重强给唯一第一。

## 3. Q3：±5% 扰动（每样本重算预算、支配、归一化与排序；N=20000，均匀独立）
- 等权第一名采样频率（不限制预算）：C 0.9748、B 0.0251、A 0.0001；
- 等权第一名采样频率（**仅预算可行者**）：C 0.4908、A 0.3538、B 0.1554（C 贴线预算导致明显跌落）；
- 完整排序变化采样频率 0.2483。
- 以上频率是**特定均匀独立模拟下的采样频率，不是真实概率**；权重不确定性与测量扰动已分开，二者联合扫描及最坏角点交 Modex。

## 4. 主路线、公式与备用
- 支配筛选（原始指标空间，逐样本重算）→ 硬预算单列（综合分不补偿超预算）→ 精确权重区域条件推荐 → 双扰动稳定性（归一化每次重算）。
- 归一化：成本型 (max−x)/(max−min)、效益型 (x−min)/(max−min)；向量归一化作对照。
- 备用：主办方给定权重则代入精确不等式；可加性受质疑则报序数稳健名次（最好/最差名次）；熵权等数据驱动权重不得称客观。
