# 2026-10-18 开发验证记录

本轮按高标准修订 Skill，未给它虚构“10/10”或奖项保证。比赛运行仍是 Skill 交接 → Modex 实现/初稿 → Skill 审查修改；豆包只参与本次制作和测试。

## 已落地的改变

- 主路线按题目输出、可行性、可辨识性和偏好条件选择；创新需有具体机制、基线与证伪方法。
- 交接模板压缩重复内容，保留逐问可执行路线；新增 Modex 回传清单。审查先处理改变答案的问题，再处理英文；复审依变更检查，复用未变证据。
- 原题要求矩阵与回传覆盖表比对，防止整问遗漏后仍通过；历史证据包兼容但警告，正式审计必须绑定矩阵。
- 新增预测信息时点检查工具，核对实际 feature-use trace；不能用“这份历史CSV现在有值”冒充“当时已知”。
- 排序变化须重查预算/支配，线性权重区域先验顶点；调度辅助变量实际进入约束，单位保留原题标签或记录转换因子。

## 实际测试及失败

三题是短合成开发探针：预测、偏好不确定排序、硬约束调度，不是三道完整官方赛题。豆包新对话分别执行任务本身、任务加候选 Skill，以及独立审查；未给执行者预期答案。原始题目和独立算术见 `inputs/`、`audit-input/`、`root-oracle.json`、`oracle-checks.json`。

首轮仍有实质错误：预测代码34次使用原点后发布的促销值，且把混合步长误差标成单步；排序单位误译100倍、实际网格步长与标签不符；调度声明了弃光但未写入平衡式。完整首轮和失败记录保留在 `with-skill-first-pass/`、`failed-information-audit.json`。不以“脚本跑通”判定这些结果正确，也不据这次对照宣称 Skill 优于基线。

审查测试识别全部8类预设问题，保留正确25°C目标；19条发现中存在同根因重复和部分不准确的修复建议，已合并和纠正。见 `root-audit-first-pass-assessment.json`、`audit-revised/`。缺少未来误差、偏好区域或敏感性计算时保留未完成状态，未伪造可提交终稿。

## 修复后独立核查

豆包按明确反馈修复，主代理继续做定点修正；这不是新一轮盲测。最终供查看的是 `root-reviewed/`，豆包自己的修订另存 `with-skill/repaired/`。

- 用 NumPy 最小二乘独立复算，8组模型×步长的 n/MAE/RMSE/bias 与修复探针一致；每步17个原点。
- 预测记录142次特征使用通过发布时间检查；实际代码复核确认 h3/4 点预测不读未知促销，情景不按未来真值选择。通过不代表未来预测准确，区间与告警成本评估仍由后续实现完成。
- 精确分数得分在5151个权重格点交叉核对完整获胜区域，并反例否定“C在全域优于D”的错误表述。
- 独立精确算术验证5个显式放松后的调度示例；原始硬约束实例仍不可行，不把修复理解为偷改原题后宣布成功。

见 `repair-verification.json`。复核命令（本开发检查需已有 NumPy；Skill 运行脚本仅用标准库）：

```bash

python3 evaluations/apmcm/with-skill/repaired/probes/probe_F_v2.py
python3 evaluations/apmcm/verify_repairs.py
python3 -m unittest discover -s skills/craft-apmcm-paper/tests
```

APMCM 22项脚本测试、原国赛102项回归和 Skill 结构校验通过。国赛核心文件未改。

## 证据边界

这是一次有反馈的开发循环。候选说明在开发中继续修订；执行器报告过相对路径写入问题，后来使用绝对路径并由主代理冻结产物，不能称严格沙箱隔离的最终版本对照试验。公开核查脚本仅调整了个人绝对路径以便移植，公开CSV统一为LF换行，数据值不变；本地首轮原始字节保留。一次配对执行不能证明因果效果或泛化，更没有真实 Token 节省计量。

尚未完成真实 Modex 往返验收、多道完整官方题的冻结版本盲测、实际 Codex 用量对照；本届未发布/未确认的AI和格式要求也不能由开发工作补造。因此本记录支持具体能力改进与缺陷修复，不支持满分、真实设备验证或最高奖承诺。
