# 2024 C：真题、可见优秀案例与数值演练

这是制作期的有边界演练，状态为 **数值复算通过，整题交稿仍不完整**。不是获奖预测，也不是作者论文复现。

先读官方题目并冻结路线，再让已有原生豆包会话产出代码及英文分析；之后对照手册的2024 C可见案例。原生豆包的两次接收属于同会话回归。独立AI审查仅收到题目、数据、代码与稿件，未收到优秀案例或预期问题；它不代表人类评委。正式比赛仍用 Skill → Modex → Skill，本轮没有付费Modex。

仅需Python标准库，从任意目录执行：

```bash
python3 evaluations/apmcm/2024c-rehearsal/check.py
```

检查器用独立的有理数/法方程实现复算预测，并在临时目录执行接收代码和来源补充代码；不改写已接受的代码与结果。它会更新本目录的`check-results.json`。可另运行`decision-checks.py`复算汇率、派生特征反例、可见收益式及三市场需求界；它更新`decision-check-results.json`。

- `strategy-frozen.md`、`freeze.json`：冻结策略、暴露背景；冻结后补充没有伪装成先验方案。
- `raw-failure.json`：原始价格—需求耦合失败，修复后仍保留失败状态。两个完整接收版本另在本地冻结，公开记录其哈希。
- `accepted/`：修复后代码、实际结果、逐原点记录、英文Summary与Q1–Q4分析；不是完整比赛论文。代码包含本题专用断言，不是通用预测工具。
- `input/source-facts.json`：第一次接收时的冻结来源状态。后来取得的全球**产量**来源单列于`accepted/global-source.json`，由`add_global_anchor.py`添加条件情景，避免回写初始未知状态。
- `reference.py`、`root-reference.json`：可运行的独立计算及最初冻结参考值；不导入接收方实现。
- `provenance.json`、`assessment.json`：过程、来源、修复与限制。原题/行业年鉴PDF、手册全文、作者论文代码和私人国赛提交包未分发。

全球消费情景依赖未估计的增长/损耗/库存假设；Q3尚未校准全球需求到中国货币产值的联动；政策参数与缓解措施可行性未经验校准。两次一步留出不能验证三年外推，数据发布时间也未核实。没有完整论文、图件与提交PDF，因此没有通过整题交稿验收。来源和案例读到哪里，见[报告](../../../docs/apmcm-2024c-rehearsal-20261031.md)。
