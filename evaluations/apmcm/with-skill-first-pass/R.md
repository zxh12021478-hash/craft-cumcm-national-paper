# R：低碳方案遴选 — Modex 交接包

阶段：思路（含已执行小检查，结果可复现）。数据：题面四方案（cost 亿元，benefit 无量纲，emissions 吨/年）；预算 12；权重非负和为 1、具体值未知。

## 1. 各问与硬约束
- **Q1** 可直接排除的方案；**Q2** 给出有依据的推荐或偏好条件；**Q3** 测量值 ±5% 扰动下排序稳定性。
- 方向：cost/emissions 越小越好，benefit 越大越好；预算=12 为硬约束，综合分不能补偿超预算。
- 权重未知 → 正确产物是**非支配集 + 权重区域条件推荐**，题目不要求唯一赢家。

## 2. 已执行检查（`probes/probe_R.py`，输出 `probes/outputs/probe_R.out`）
- **支配筛选**：B（cost10, ben80, em7）对 D（11,75,8）三维全面不差且严格更优 → **D 被支配，排除**；A、B、C 互非支配；四方案名义成本均 ≤12（C 恰好 12）。
- min-max 归一化（成本/排放 (max−x)/(max−min)、效益 (x−min)/(max−min)）得分：
  A(1,0,0.667)、B(0.5,0.667,0.333)、C(0,1,1)、D(0.25,0.333,0)。
- 权重单纯形 0.02 步长枚举（231 格点）：C 独占 58.9%、A 35.9%、B 2.6%、D 0，平手 6；**等权 C 胜（0.667>A 0.556>B 0.5>D 0.194）**。
- 归一化敏感性：向量归一化等权下 A 0.536 > C 0.530 > B 0.500 > D 0.448，**A/C 第一名随归一化翻转**——必须如实报告。
- ±5% 联合扰动 2000 次（等权、min-max、每次重新归一化）：C 胜率 96.9%、B 3.0%、A 0.1%，完整排序变化 24.9%。

## 3. 主路线（输入→计算→输出→检查）
1. **支配筛选**（原始指标空间，与权重无关）→ 排除 D；硬预算单列。
2. min-max 归一化加权得分 S_i=w_c·C_i+w_b·B_i+w_e·E_i；在权重单纯形上给**解析胜出区域**（min-max 下，令 w_c+w_b+w_e=1，Modex 须复算）：
   - C≥A：w_c ≤ 0.5−w_e/3；C≥B：w_c ≤ 0.4+0.4w_e；
   - B≥A：7w_c+6w_e ≤ 4；A 仅在高成本权重角（w_c≈≥0.57）胜，B 仅在 w_c≈0.4–0.57 窄带胜。
3. **Q2 推荐**：等权/无强偏好 → C；偏好低成本（高 w_c）→ A；B 无稳健优势；给权重区域表而非唯一结论。
4. **Q3 稳定性**：原始指标 ±5% 独立联合扰动 + 每样本重新归一化 → 重算排序，报告各方案胜率、排序反转率、最大后悔值；权重扫描与测量扰动**分开**再做联合；加最坏角点（同向极值）。
5. 预算稳健性：C 成本零余量，最坏角点 12×1.05=12.6>12，须报告 C 在硬预算下的扰动失效概率；同样检验 D 支配在角点是否仍成立。

## 4. 基线、验证与备用
- 基线：等权 min-max 综合评分（最常见默认做法）；改进=权重区域划分 + 双扰动分离，避免"假客观"权重。
- 对照/证伪：min-max 与向量归一化并行报告；权重单纯形步长减半（0.01）复核区域边界；蒙特卡洛 ≥10⁵ 次（探针仅 2000 次）。
- 备用：若主办方后续给权重，直接代入对应区域；若争议可加性，改报序数稳健性（各方案在所有合法权重下的最好/最差名次）。
- 熵权法等数据驱动权重**不得**称为客观权重（仅反映样本离散度）。

## 5. 关键公式与单位
| 用途 | 公式 | 说明 |
|---|---|---|
| 成本型归一化 | (max−x)/(max−min)；效益型 (x−min)/(max−min) | 扰动后必须重算 |
| 综合分 | S_i=w_c C_i+w_b B_i+w_e E_i，w≥0, Σw=1 | 单位：亿元/无量纲/吨·年⁻¹ |
| 硬预算 | cost_i≤12 才可入选 | 与综合分分开判定 |
| 稳定性 | 胜率=排第一次数/试验次数；后悔=S_best−S_i | 胜率非真实概率，须注明 |

- 未胜出不等于被支配（B 非支配但仅窄带胜出）。
