# O：硬上限下可再生能源调度 — Modex 交接包

阶段：思路（含已执行小检查，结果可复现）。三时步：负荷 [4,7,5] kWh，电价 [1,4,2] 元/kWh；g_t≤5 kWh；光伏仅 h2、s∈[0,4] 且日前承诺时不可观测；电池容量 3、E0=0、充放功率≤2、充放效率均 0.9；禁止外送与弃负荷、E3=0。

## 1. Q1：对所有 s∈[0,4] 保证可行的计划不存在（已执行 `probes/probe_O.py`）
**不可行证书（最坏 s=0，总量平衡）**：
- 总负荷 16 kWh；电网总上限 3×5=15；
- 电池 E0=E3=0、η=0.9：净供出 = (η²−1)·Σc ≤ 0（η²=0.81），电池不能创造能量；
- 故 s=0 时最大供给 15 < 16，**对 s∈[0,4] 全程鲁棒可行：不成立**。
- 逐时夹逼（cap=5）：h1 负荷 4 后最多充 1（c1≤min(2,5−4)=1）→ E1=0.90 → h2 最多供 0.81；h2 平衡 5+s+0.81≥7 ⇒ **保证可行的最小 s*=1.19 kWh**；h3 由 g3=5 恰好覆盖。
- 放松对照：cap=6 时 h1 可充 2、h2 供 1.62，h2 合计 7.62≥7、总电网 18≥16，s=0 即可行（Modex 须复算）。

## 2. Q2：可辩护的规划/追索模型（两阶段，鲁棒）
**时序定义（防完美信息泄漏）**：
- 日前（here-and-now，不可依赖 s）：g_1,g_2,g_3 与 h1 充放电 c_1；
- 实时（h2 观测 s 后，wait-and-see）：h2/h3 的充、放、光伏消纳（含弃光变量 q_2≥0）。
- 约束：
  - 平衡 g_t+s_t·1{t=2}+d_t = L_t+c_t（c/d 为电池侧，按效率约定）；
  - E_t=E_{t−1}+0.9c_t−d_t/0.9，0≤E_t≤3，E0=E3=0；
  - 0≤c_t,d_t≤2；0≤g_t≤5；g_t+s_t≤L_t+c_t（**无外送**）；q_2=s−实际使用，q_2≥0（允许弃光，不强制注入）；
  - 日前变量对所有 s 相同，追索约束对 s∈保证区间逐点成立（线性模型验顶点即可，数值上加密网格复核）。
- 目标：min Σ price_t·g_t（无 s 概率分布 → 不默认期望成本最优；给鲁棒/最坏情形；若后续提供分布，改情景两阶段随机 LP）。
- **所需假设/放松（三选一，报主办方）**：① 主办方提供最小光伏保证 s≥1.19 kWh；② 电网上限放宽到 6；③ 允许有限弃负荷并定价（违背原题 no shedding，须显式批准）。另须说明：g3 若日前锁死 5，则高 s 时光伏经电池转移到 h3 会过供，需允许 g3 日内下调或直接弃光。
- 对照基线：用真实 s 的当日 LP（完美信息，仅作不可达成本下界，并演示其计划在日前不可实施）。

## 3. 一个可检验改进
- 改进=**先证书后优化 + 显式追索**：在求解前用总量/逐时界给出不可行证书与最小保证 s，再求两阶段鲁棒计划；对照"把 s 当已知"的单阶段 LP，证明后者虽数值最优但不可实施。
- 证伪：若鲁棒计划在 s∈[s*,4] 加密网格上任一点违反平衡或终态，即撤回；失效条件：s 保证、容量放松均不被接受 → 只能回 Q1 结论。
- 备用：连续区间不 tractable 时，用端点 s={s*,4}（及需要时拐点）情景集；可加充放互斥约束（c_t·d_t=0 或二进制）。

## 4. Q3：阻止"数值好看但物理不可行"的独立检查
- 独立于求解器状态逐时重算：平衡方程、E_t∈[0,3]、E0=E3=0（容差建议 1e-6）、c/d≤2、g≤5；
- 总量恒等式 **Σd = 0.81Σc**（净损 19%）；逐时无负储能、无外送、无免费初始能量；
- 同时充放扫描：LP 松弛解中 c_t>0 且 d_t>0 即判无效（亏损套利伪解）；
- 泄漏测试：交换 s 取值，日前 g、c1 必须完全相同；s 只影响 h2 起变量；
- 鲁棒性：s 顶点 + 0.01 步长网格全检；独立重算目标成本与求解器值比对；
- 单位检查（kWh 与元/kWh 不混）、终态为零报告实际残差。
