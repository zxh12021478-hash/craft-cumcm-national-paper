## 真实观察与处理

| 风险 | 原始/候选实际行为 | 接受的处理 |
|---|---|---|
| 分类预测偷看标签 | 原代码按`y_all`选本对数据，只在这些行投票；候选仍写每样本“两票” | 每个测试样本运行全部三对；纯预测接口无评估标签，冻结模型后检查标签变动不影响预测 |
| 量化步长当容差 | 原RBF/P=1残差0.06667约为1/15，旧判据却放行 | 共享网格检查整数和为零；原0.9933/0.9733投票指标撤回，没有模型参数就不补写新准确率 |
| 高阶式冒充QUBO | 学习β并与二值权重相乘后仍沿用原二次规模 | 小例布尔展开出现四次项；选择固定特征的二次输出头，或重新推导降阶与总变量数 |
| 修复新增错误 | 候选给`xy-xz-yz+z`作AND惩罚，两个非法赋值能量为零 | 八行真值表反例；正确示例`xy-2xz-2yz+3z`仅合法赋值为零，整体惩罚强度还需核对 |
| 比较口径变化 | AR不同阶用8/7/6个响应直接排BIC | 共同6个响应重算，p1/2/3为-27.438/-25.7465/-24.8026；不升级为外推精度 |
| 失败归因过强 | 候选0.9611小例同时改变类别、特征、池化、阈值范围、采样和求解器 | 只支持修改后小例的生产者结果，不能归因“只有归一化修好了原10分类模型” |
| 假反验 | 候选`hidden_label_invariance=true`来自相同参数调用两次 | 不计作标签隐藏实验；本地修正接口另做固定模型反验 |
| 备用变成另一问 | 普通二值矩阵分解被当成深度学习问的完成替代 | 保留原题规定模型类型；修订交接给出深度特征+QUBO头的待验证路线，不预填性能 |
| 计算膨胀 | 交接前展开多阶/位宽/核/惩罚/重启；回归又把24位枚举叫极小 | 先计算`2^n`，表示/接口检查用少变量或冻结模型；完整实验留给Modex |

候选还把每类30个测试样本后的二类训练数写成60或70；150个样本、三类各50，留下每类20训练，故每对40行、4位编码160位。修订版按实际划分核算。原要求与本方位宽、超参数、性能门槛分开。

候选声称的“规范四档”也不是强制禁止其他描述性标签。其社区包安装/矩阵API实测只有生产者记录，没有独立保留的命令输出，不提升为主代理验证。完整Kaiwu SA始终未运行。[官方SDK概述](https://kaiwu-sdk-docs.qboson.com/en/latest/source/getting_started/introduction.html)将本地经典优化器与硬件后端区分；不能把任意NumPy退火或文档查阅当成指定SDK成功。

## 可重跑的本地证据

仅需已有NumPy；下面两个命令不训练模型、不联网、不调用SDK，通常很快。不要为复核这些结论运行归档中的全部24位探针。

```bash
python3 evaluations/apmcm/historical-handoff/independent_checks.py
python3 evaluations/apmcm/historical-handoff/minimal_contract_check.py
```

- AR64组、SVM64组、原二值头16组赋值与解码原目标一致；最大误差小于1e-9。这是小例表示核对，不是大实例最优性或SDK兼容性验证。
- 另16组布尔展开证实学习β可产生四次项；8组AND真值表证实候选错误与修正惩罚的区别。
- 分类反例固定特征/分类器，只换评估标签，旧预测改变；本地修正接口不接受评估标签、全部三对投票，三个标签排列预测不变。只检验这个接口，不声称修好了整套Iris训练代码。
- 共同响应窗口BIC由主代理独立实现，和候选JSON的四舍五入结果一致。
- 原完整探针数值及候选0.9611结果未全量重跑；按生产者结果保存，不赋予已独立复现状态。其模型/样本预测未完整保存，不能恢复新的全量指标。
