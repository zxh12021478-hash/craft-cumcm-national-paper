# 按题型解除关键风险

仅阅读相关小节；这些是决策检查，不是固定算法清单。混合题沿用同一状态、单位和约束，把上游不确定性传至下游。

## 预测 / 统计
在实际预测时点定义可用信息集及每个特征的发布时间；已结算、回填或未来实现变量不能进入历史预测。多步预测按每个 horizon 核对特征可得性；未来外生变量未知时用明确情景或不使用，不能悄悄填入真实未来值。基线采用与周期/业务匹配的简单预测，训练变换和选参只在各训练折内进行；用滚动/扩展窗口按实际多步任务检验，随机打散不适用于时间外推。训练残差和拟合 R²不能当样本外精度或区间覆盖率。历史 CSV 存在某字段不等于当时可知；滞后一期也可能仍未发布。有未来/延迟特征的实际试算按 `forecast-information.md` 核对代码和时点，可用 `scripts/check_information.py` 检查实际特征使用记录。

趋势/机制变化时比较局部窗口或分段结构；少数据先控制自由度。报告各步误差、偏差、区间覆盖和宽度，阈值来自任务或明确标注的分析选择。告警按误报/漏报成本决策，区分点预测阈值与事件概率阈值。跨折汇总按声明的预测单元重算 RMSE=√(Σe²/N)，不直接平均各折RMSE；窗口重叠时说明原点×步长计数，不伪称独立样本。描述性预测不能直接支持因果政策。

不同滞后阶数的条件似然/信息准则须基于可比较的响应样本和同一似然约定；不能直接把各自截去不同长度前缀所得的数值排名当成可靠定阶证据。少量观测时保留小样本限制，不把训练拟合优度写成预测准确率。

## 监督学习 / 分类

冻结按原始样本 ID 的训练、选参和测试划分；同一样本的派生表示不能跨集合。预处理只在训练数据拟合。多分类拆成二分类时，训练子集可按训练标签选取；完整分类评估应在共同测试集上运行所有适用分类器并明确平局规则，不能把分别划分的二分类准确率当成完整多分类精度。

预测接口只接收特征和已冻结的模型/状态，不用真实测试标签来决定运行哪个分类器、排除哪个类别或给谁投票。一个便宜的反验是：固定输入特征、模型和随机状态，仅置换/隐藏评估标签，预测结果必须不变；标签只用于之后计算指标。这个检查发生在训练后，不禁止训练和分层划分正常使用标签。保存测试 ID、实际标签与预测、必要的模型参数，避免只剩聚合准确率而无法追查。

若修改架构、训练样本或目标后才得到性能，结论只适用于修改后的模型。随机/冻结特征加可训练输出层须说清优化了哪部分；不能称为整个深度网络已经训练，也不把头部二值化后明显失败的结果说成路线已验证。切换更灵活的头部仍是待验证备选，而非自动获得原连续模型的效果。

## 评价 / 排序 / 决策
先确认指标方向、单位、可替代性、重复信息和权重含义，作支配筛选。比较前说明指标定义、归一化和权重来源，不为得到期待赢家事后调整；缺资料不等于零分。归一化、权重和阈值本身可能决定赢家；熵权反映样本离散程度，不等于客观重要性。未知偏好时给非支配集合、权重区域或条件推荐；可以没有唯一无条件第一名。线性加权得分的获胜区域须同时满足对所有竞争者的不等式；声称某不等式在权重单纯形上恒成立前先验顶点，不能把条件胜出误写成全域支配。

把权重变化与原始测量扰动分开，并重新判断硬约束可行性、支配关系、归一化和排序；名义支配不能永久剔除扰动后可能有效的方案。检验联合扰动、排序反转和推荐后悔值；采样权重下的胜率不是实际可靠概率，未胜出不代表被支配。若需投资/选址决策，把硬预算和可行性单列，不能用综合分补偿违法约束。

## 优化 / 调度 / 网络
先用总量、时段、割集、容量和边界条件给必要可行性界，再调用求解器。储能/流量/库存跨期守恒，损耗和终态不能遗漏。用不可行证书回答不可能的问题，明确需要放宽的约束；不能静默引入负库存、外送、弃负荷或免费初始能量。

不确定参数何时可见、哪些决定先提交、哪些能追索应先定义；已观察未来再回填日前决定会形成完美信息泄漏。没有概率依据不默认期望成本最优；按任务选情景/鲁棒/机会约束并解释依据。模型引入的弃光、弃负荷或追索变量必须实际进入对应约束；在明确放松后的模型上用一个可行例反验方程，不能只在文字中声明。求解器状态之外独立重算目标、守恒、硬约束和整数性；区分可行解、候选集最好与有最优性证据的解。相同预算和边界比较基线。需要优化结果验收、多目标算法对照或最优性主张时读 `solver-review.md`，可用标准库脚本独立检查线性部分；不默认启动全量求解。

## 机理 / 工程 / 仿真

图像/几何测量题按 `image-geometry.md` 把定位、尺度与误差传播衔接到实际输出；亚像素重复性不是实物精度。
先判断可观测量能否识别参数；不可辨识时重参数化、给区间或增加测量，不靠复杂优化制造唯一值。核对几何、边界、量纲及耦合守恒；负载、输入电功率、热功率与能量不能混用。先做解析极限与稳定性小试，再扩展计算。

数值验证与实测验证分开；参数校准数据不同时当独立验证。时步与网格分别细化，连续方程/参数含义必须不变。若推荐对简化机制或参数范围敏感，给适用范围和失效信号。需要深查时读 `physical-validation.md`，不要求每题开展硬件实验或大规模 CFD。

## 指定表示 / 受限求解工具

原题指定模型、编码、算法或变量数上限时，把它们当要求核对；通用求解器、经典参考解可作比较，不能替代指定工具的完成状态。分清数学表示已核对、当前 API 已查阅、依赖可导入、指定求解器已实际运行；记录真实版本和运行证据。旧示例与当前接口冲突时先查所用版本，不凭文档标题填“最新版已跑通”。工具暂不可用可先交接路线和明确待办，不能把整题标完成。

对 QUBO 等离散表示，明确变量顺序、取值范围、精度、解码、常数项及辅助变量；先算每次实际求解的总变量数，降次/松弛变量也计入。新增可学习缩放、变量乘积或非线性激活后，重新展开最高次数；原来是二次不代表修改后仍是二次。若需降阶，给辅助变量关系、惩罚和新规模，再交作可实现路线。原模型与离散/简化模型的差别单列。用极小实例逐个赋值比较“原目标及约束→编码能量→解码结果”；QUBO 上三角与对称矩阵的交叉项系数、常数偏移尤其容易出错。此检查核对表示，不建立指定 SDK 兼容性或大实例最优性。

惩罚能量低不等于原约束已满足。独立解码并检查原等式/不等式；参数量化步长不是等式可行性容差。共享有理网格上的等式可检查整数加权和是否为零，浮点运算误差则另给有依据的容差。发现非零残差时按不满足原约束处理，或明确报告近似模型；不能因分类准确率高而放行。SDK 内经典模拟退火、硬件求解与实际加速证据分别报告。

求得的能量优于随机候选，仍不足以排除求解误差或证明模型本身有缺陷；归因需要界、可比的精确小例或独立证据。切换备用场景/模型时重新核对原题规定的模型类型与输出，较容易求解的替代问题不能自动算原问完成。
