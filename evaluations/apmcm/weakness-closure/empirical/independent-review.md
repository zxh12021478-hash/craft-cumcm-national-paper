# 实测校准接收产物独立审查

结论：**算术和冻结预测获得独立支持；交接须修正留出集用途，才适合直接执行。** 本次四点上饱和模型误差较小，但这不是物理机理、饱和容量或广泛样本外准确性的证明，也不是奖级认证。

## 检查范围与方法

只读任务允许的 `plan-frozen.md`、`freeze.json`、`receiver/train.json`、`raw-frozen/{fit.py,results.json,report.md,handoff.md,done.json}`、`holdout-private.json`，以及指定源码 Skill 的入口、physical-validation、route-challenge、modex-handoff；另读了任务要求的 skill-creator 独立测试说明。未读根检查器、根结果、accepted、其他案例或审查结论；未联网、安装或调用外部服务。所有检查代码、隔离重跑及结果写在本目录，未修改原产物。

`check.py` 用独立的稳定指数运算、2001点对数扫描和剖面导数变号后二分，复核饱和模型；用闭式最小二乘复核仿射模型。按源码预期的 `../train.json` 相对布局复制到本目录重跑原代码。留出指标始终使用原 `raw-frozen/results.json` 的冻结预测，没有用重跑值替换，也没有据标签调整参数、模型或搜索。

## 通过的数值检查

- 冻结计划哈希，以及 done 中四份文件哈希均匹配；这仅验证产物对应关系，不证明语义正确。
- 独立仿射结果：a=2.079883928246243，b=0.11257235325320837，RSS=2.267399187992365。
- 独立饱和结果：A=220.8344971607512，k=0.0006004720648865609，RSS=0.006464644645055866；剖面导数约 7.7×10⁻¹⁰。扫描只发现一个负到正的导数括区，最优点在内部；两端RSS约10.5996、2168.6581。冻结预测与独立解的最大差约4.1×10⁻⁹。支持本次优化结果，但不把有限扫描称为一般全局最优证明。
- 原码干净重跑不逐位相同：A差5.1×10⁻⁷、k差1.5×10⁻¹²、RSS差2.4×10⁻¹⁶、四预测最大差2.2×10⁻⁸。数值差异不改变报告精度下的结论，不据此判定拟合失败。原因未单独定位。
- 训练RSS比为350.738，支持“约350倍较小”的训练拟合比较。原码确实只从训练JSON读取十个响应和四个预测压力；不能由此认证同对话中的人员或接收者此前从未见过完整基准。

这支持“在该已知基准、固定十点拟合与四个较高压力点的有限比较中，冻结饱和模型误差较小”。这是按压力划分的回顾性外推检查；不是新采集实验、严格盲测、时间预测或独立同分布泛化保证。父级已见完整数据、基准可能被记忆的限制已在冻结计划披露，不将其误报为本次新发现的泄漏。

## 需要修复的交接问题

1. **会改变评估有效性：`handoff.md` “Next meaningful executable check”第3步。** 它把“若饱和留出RSS较小便保留为推荐模型，否则保留基线”称为“predeclared decision rule”。`plan-frozen.md` 实际预声明的是固定候选和预测后比较MAE/RMSE/max及有符号残差，并禁止依评估标签调模型集、搜索和划分；没有预声明这个选模规则。接收者新提出的规则不能追认为事前规则。依最终留出结果选择推荐模型后，这四点就是选择数据；即使没有重拟合参数，也不能再称其为所选模型独立的最终性能评估。**最小修复：**删除该“predeclared”表述与选模指令，保留固定候选的有限比较并报告差异和失败区域。若确需据此选模型，应明说已用于选择；只有还需要独立性能主张时，才另作独立评估，不强制为本次有限比较新增数据。
2. **诊断要求漏传：同节第2步。** 它只要求绝对误差、RSS、最大误差，未完整传递冻结计划要求的MAE、RMSE和有符号残差。RSS与RMSE在本次同样四点上排名一致，故不是当前排名算错；但只看绝对量会丢失四点同向且随压力增大的低估信息。**最小修复：**补齐上述指标并注明残差方向；保留原冻结预测，勿在看到标签后修正它们。

## 较小的准确性与证据边界

- `report.md` 的“largest magnitude 0.065 at the ninth point”及后文“ninth-point residual”应为第8点，压力378.4，残差−0.0653688；第9点为+0.0156009。修正文案即可，不影响拟合或四点比较。
- `fit.py` 把 `converged_interior` 直接定义为 `K_LO < k_hat < K_HI`。内部位置本身不是收敛检验；本次由实际窗口缩小和独立导数求解补足证据，未发现优化失败。可将字段改为 `interior_solution`，并另存停止条件；无需为此重做模型路线。`refine_log` 的window误写为两个win_lo，但未进入交付结果、也未参与拟合，是低影响日志笔误。
- 报告正确指出真实机理与参数不确定性未建立，也明确指出物理解释需要实验背景和不确定性。交接第4步只列剖面区间和残差检查，宜把报告中的外部实验背景/测量不确定性要求一并带走；区间与残差本身不能验证吸附机理或设备。当前无需为描述性比较追加物理实验或强制置信区间。

未发现需要撤回原冻结数值或重新拟合的算术错误。未量化A与k的参数权衡，故也没有据这些点认证饱和容量可辨识；未认证仪器精度、物理装置、超出这些压力点的泛化或任何奖项。
