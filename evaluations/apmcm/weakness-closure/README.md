# 实测校准、跨问联动与完整稿制作演练

这组证据补强的是建模、交接和审查能力。计算检查通过，**完整内容验收仍拒绝放行**：全球消费/产业估值与现实政策参数缺少校准。它不是正式提交包、未知题盲测或奖项概率评估。

从仓库根目录运行，计算部分仅需Python标准库：

```bash
python3 evaluations/apmcm/weakness-closure/check.py
```

入口执行三项检查：NIST实测留出、2024 C条件桥接/解析政策、干净目录重现；再运行现有生产账本检查器。预期结果是29条摘要数值无错误，同时Q2/Q3/Q4的内部证据门槛保持失败。入口退出成功只表示这些预期行为成立。

- `empirical/`：公开NIST观测的10点拟合和4点较高压力留出。原接收产物保留在`raw/`，修复交接在`accepted/`；参数与预测没有按留出结果重新拟合。源单位未说明，不编造Pa或毫升。该基准已经公开暴露，不能再称未见测试，也不验证2024 B空调设备。
- `case/`：完整英文Markdown稿、Summary、29个标量映射、逐年结果、四幅源数据SVG、代码和复跑入口。三个原始问题仍缺少经验支持，未用“文件齐了”替代内容验收。历史训练PDF已在本地生成并逐页检查；公开目录分发可复算文本/代码/图件及PDF检查记录，不分发该二进制文件。
- `raw-v2-ledger-audit.json`：接收方二次修复后，最初适配产生16条拒绝，其中4条是根适配错误；修正千位分隔符后仍有12条映射问题，见`normalized-raw-map-audit.json`。未把“自查通过”计为通过。
- `check-results.json`、`assessment.json`：当前检查与范围。首次根检查把12个容量成本情景误标为18，已更正；原始错误记录保留在本地，不作为当前计数。

制作期复用了同一原生豆包会话，共三次任务：实测拟合、完整初稿、定向修复。隔离AI对实测交接及完整稿作了审查；它不是真实评委，完整稿后的逐年政策补充由根计算核对。未调用付费Modex；正式比赛仍保持Skill → Modex → Skill。
