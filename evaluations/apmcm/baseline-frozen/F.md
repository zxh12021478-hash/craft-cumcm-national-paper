# F 题交接包：周度需求预测（81–84 周）与高需求预警

## 0. 信息可用性（硬约束，建模时必须严格遮蔽）
- 原点=第 80 周末。可用：demand 1–80；promotion 已知到第 82 周（metadata：81=0、82=1，83/84 未知）；service_tickets 延后一周定稿，原点处仅到第 79 周。
- demand 在其周末才实现，禁止用同期 tickets 当解释变量。

## 1. 已执行检查（check_F.py / check_F_output.txt，事实，非预测承诺）
- 增长存在明显换挡：每 20 周均值 86.16 / 95.53 / 105.49 / 139.51；周 80 实际值 157.97。
- 全局线性模型 y=a+b·t+c·p：b≈0.845/周，促销系数≈6.36，残差 SD≈9.97，残差 AR(1)≈0.66（线性趋势明显欠拟合）。
- 分段线性（单折点）全样本拟合：折点≈周 55，前/后斜率 0.43 / 2.15 单位/周，促销系数≈6.2，残差 SD≈5.74。
- 滚动原点回测（外原点 44–76，共 33 个；每原点重拟合；h≥3 促销按边际频率 0.287 替代）：
  - 基线（线性+促销）RMSE：h1–h4 = 13.0 / 14.2 / 15.2 / 16.1；
  - 分段线性（折点由内层滚动选择）RMSE：6.4 / 6.7 / 7.2 / 7.1，改进显著。
- tickets 同期 z_t≈1.60·y_t（相关 0.9998），但不可用；滞后项 z_{t−1} 在全局模型中把残差 SD 从 10.0 降到 7.7，是否纳入分段模型由滚动 CV 决定。
- 全样本分段模型点预测仅作流程演示：81=160.1（无促销）、82=168.4（有促销）、83=164.4/170.6（无/有促销）、84=166.5/172.7。

## 2. 主路线（Modex 实现）
模型：y_t = β0 + β1 t + β2(t−k)_+ + γ p_t + u_t，u_t = φ1 u_{t−1}+φ2 u_{t−2}+a_t（OLS 起步，AR 项按显著性保留）。
- 折点 k 在候选网格 {25,…,o−10} 内用**内层滚动原点**（h1–4 平方误差）选择，禁止用外样本。
- 多步预测：h=1,2 用已知 p；h=3,4 促销未知，给 p=0/1 两条路径，并按边际频率 0.287（建议用近 40 周平滑频率）混合，同时给出两种极端情形。
- 不确定性：残差 bootstrap + AR 递推，模拟 ≥10000 条路径，按 h 输出 P10/P50/P90 及 P(y>150)；区间随 h 自然展宽。

## 3. 一个改进机制
显式建模"增长换挡"：分段线性趋势 + 滚动 CV 选折点（仅此一个结构性改进；其余变量保持克制）。

## 4. 预警规则（成本不对称，FN=5，FP=1）
每周边际最优：报警当且仅当 P̂(y_{80+h}>150) > 1/(5+1)≈0.167（即 P83.3 分位>150）。对 81–84 逐周判定并给期望成本。

## 5. 基线（必须同时实现并对照）
(a) 朴素：漂移法 random walk with drift；(b) 全局线性趋势+促销 OLS；(c) 预警基线：固定均值+1.28σ。

## 6. 验证设计（模拟真实预测原点）
- 外原点 44–76（保证 h4 有实际值），逐原点重拟合、严格遮蔽：promotion 只提前 2 周、tickets 滞后 1 周、h3/4 促销未知。
- 报告：h1–h4 的 MAE/RMSE/bias；P10–P90 区间经验覆盖率；预警的 5·FN+1·FP 总成本，并与"从不报警/每周报警"对照。
- 报告必须明确：回测覆盖的是 44–80 区段，对 81–84 不外推精度承诺，若未来再次换挡需以新数据滚动更新。

## 7. 兜底
折点选择不稳（相邻折点 RMSE 差<5%）→ 退阻尼趋势 ETS 或局部线性状态空间模型；区间欠覆盖 → 直接用滚动误差按 h 的经验分位；滞后 tickets 若在 CV 中无效则剔除。
