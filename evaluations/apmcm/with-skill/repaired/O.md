# O 修复版：硬上限下可再生能源调度 — Modex 交接包

首轮问题：弃光 q 已声明却未进入逐时平衡（仍用 s_t）；c/d 侧术语错误；放松模型缺可行例反验。已执行 `probes/probe_O_v2.py`（输出 `probes/outputs/probe_O_v2.out`）。**原题不可行结论保持不变。**

## 1. 统一变量与约定（全文一致）
- c_t：**充入侧能量**（从电网/光伏取，效率前）；d_t：**供负荷侧能量**（效率后）。
- 储能：`E_t = E_{t−1} + 0.9 c_t − d_t/0.9`，0≤E_t≤3，E0=E3=0；0≤c_t,d_t≤2。
- 光伏利用量 u_t ∈ [0, s_t]（s_t 仅 h2 非零），弃光 q_t = s_t − u_t ≥ 0；**逐时平衡用 u_t 而非 s_t**：
  `g_t + u_t + d_t = L_t + c_t`；无外送 g_t+u_t ≤ L_t+c_t；0≤g_t≤cap。

## 2. Q1：原题不存在对所有 s∈[0,4] 保证可行的计划（已独立重算）
- 总量：ΣL=16 > 3×5=15=Σg 上限；E0=E3=0 时电池净供出 = (0.81−1)Σc ≤ 0，不能创造能量；s=0 即缺口 1 kWh。
- 逐时夹逼：h1 供负荷 4 后最多充 c1=1 → E1=0.90 → h2 最多供 d2=0.81；5+s+0.81≥7 ⇒ **最小保证 s*=1.190 kWh**。
- 负对照已验证：同一计划在 s=1.0 时 h2 平衡 6.81<7，模拟判不可行。

## 3. Q2：两阶段鲁棒规划/追索 + 显式放松（均已反验）
- 决策时点：**日前**（不依赖 s）：g1,g2,g3 与 c1；**实时**（h2 见 s 后）：u2,q2,d2；g3 不做日内调整（已被反验覆盖）。
- 目标 min Σ price_t g_t；无 s 概率分布，不默认期望成本，按鲁棒/最坏情形处理。
- **放松 R1（已验证可行）**：主办方保证 s≥1.19。日前固定 g=[5,5,5]、c1=1；实时 d2=0.81、u2=1.19、q2=s−1.19。s∈[1.19,4.00] 步长 0.01 共 282 点独立逐时模拟全部通过（E3=0、总量恒等式 Σd=0.81Σc=0.81），成本 35.00；s=4 时弃光 2.81。
- **放松 R2（短可行例，已验证）**：cap=6、s=0。g1=5.2346、c1=1.2346（=1/0.81，使 d2=1.0 恰好耗尽储能），g2=6、d2=1.0，g3=5；逐时平衡与 E0=E3=0 通过，成本 39.2346。
- 放松 R3（须主办方显式批准）：允许有限弃负荷并定价，违背原题 no shedding。
- 完美信息基线：用真实 s 的当日 LP 仅作不可达成本下界，其计划在日前不可实施。

## 4. 一个可检验改进
- 先证书后优化 + 显式追索：s*=1.19 与 R1/R2 可行例在求解前给出；对照把 s 当已知的单阶段 LP 证明其不可实施。证伪：R1 计划在保证区间加密网格上任一点违反约束即撤回；放松均不被接受则回到 Q1 结论。

## 5. Q3：独立于求解器的物理检查（逐时重算，容差 1e-6）
- 平衡 g+u+d=L+c；0≤u≤s、q=s−u≥0；E 边界与 E0=E3=0；c/d≤2、g≤cap；
- 总量恒等式 Σd=0.81Σc；无同时充放（c_t·d_t=0）；无外送、无免费初始能量；

- 鲁棒性：s 顶点 + 0.01 网格全检（R1 已覆盖）；独立重算目标成本；kWh 与元/kWh 不混。
