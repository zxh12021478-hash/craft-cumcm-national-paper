# 主代理复核与修订

原始豆包输出独立保存在 forward-output/，没有改写其记录。A标称周长20 mm、面积24 mm²以及精度不支持结论正确，B场误差与方案反转正确；但交付仍有缺陷：

1. A交接过长，计算390625个误差网格点；标定一项反例已足够决定“不支持”，根版本收束为小检查和Modex后续任务。
2. A把凸性泛化成极小值在顶点、用密网格支持严格最坏界，论证不充分。此矩形周长下界可由两条长边各≥119、两条短边各≥79证明396 px且可达到；最大值可由凸性在顶点枚举；面积需含1/2并单独利用多重仿射及符号不变证明。根交接不需要这些更强结论，予以删除。
3. A改善建议对不同误差项分别设限，没有保证叠加后满足统一目标；根版本改为联合预算，并保留独立实物参考缺口。
4. B摘要引入了正文尚未报告的MAE/RMSE等新核查指标，且原摘要文件混入审查说明，不能直接整体粘进论文。根版本先把所选新指标补入 paper-B.md 的Q1正文和 results-B.json，再交付只含摘要的 summary-B.md。未改输入、模型或原模拟数据。
5. B审查中的原文行号多处不精确；根版本用章节标题与JSON字段定位。替换范围按唯一Summary标题到下一章节；核查范围放本记录，不进入论文。仍无可执行模拟器/PDF/实测数据/当前官方模板，不能宣称这些检查通过。

这些是有反馈的开发修订，未进行第二轮完全冻结的独立最终版本试用，不声称整题/正式Modex表现已验证。
