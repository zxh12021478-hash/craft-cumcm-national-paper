# Task A → Modex 紧凑策略交接：矩形轮廓标定与几何测量

> 微型原创题（非赛题、非完整论文）。同平面、等比例、忽略畸变；所有误差为**确定性界**，不设概率分布。证据仅来自 request.md 题面；已执行探针见同目录 probe_A.py / probe_A_result.json。

## 1. 原题要求与已知输入
| ID | 必须回答 / 单位 | 输入 | 硬约束 |
|---|---|---|---|
| Q1 | 标称周长（px、mm）与面积（px²、mm²）；约定点序 | 轮廓点 (0,0),(120,0),(120,80),(0,80)，沿序闭合 | 单位 pixel；闭合约定 |
| Q2 | 能否支持“实物长度精度 ±0.02 mm”；误差分析；还需证据 | 标定 200 px = 10 mm（10 mm 精确，标定像素距离 ±2 px）；每顶点每轴 ±0.5 px | 无独立实物真值；不得转成概率问题 |

## 2. 主路线、已核对答案与 Q2 判定
**每问 输入→计算→输出（探针已核，数值可直接用）：**
- **Q1**
  - 点序约定：P1(0,0)→P2(120,0)→P3(120,80)→P4(0,80)，闭合边 P4→P1；标准直角坐标（x 右 y 上）下为 **CCW**（有符号 shoelace = +19200）；若按图像坐标（y 下）叙述，视觉上呈 CW——正文必须写明所用坐标约定。
  - 周长 = Σ 欧氏边长（禁止用端点距离代替弧长；本题轴对齐时 = 2(W+H)）；面积 = ½|shoelace|。
  - 标称：尺度 s = 10/200 = **0.05 mm/px**；周长 **400 px = 20.0 mm**；面积 **9600 px² = 24.0 mm²**。
- **Q2：判定为不支持。** 区间/最坏情况传播：
  - 尺度：s = 10/D，D ∈ [198, 202] → s ∈ [0.049505, 0.050505] mm/px，最坏相对界 **1.0101%**。
  - 定位（8 个坐标分量各 ±0.5 px，256 个框角点枚举，边长凸、shoelace 多重仿射，极值在框顶点；390 625 点密网格复核一致）：长边 ∈ [119, 121.004] px，短边 ∈ [79, 81.006] px，周长 ∈ [396, 404] px，面积 ∈ [9401, 9801] px²。
  - 物理极值（最坏 px × 最坏尺度）：长边 **[5.891, 6.111] mm**，短边 **[3.911, 4.091] mm**，周长 **[19.604, 20.404] mm**，面积 **[23.039, 25.00] mm²**。
  - 决定性理由（任一即否决）：① 仅**单个顶点** 0.5 px = 0.025 mm 已超过 0.02 mm；② 边长为两顶点之差，定位界 ±1 px = **±0.05 mm**；③ 仅标定尺度在 6 mm 长边上就 **±0.0606 mm**；长边综合最坏 **+0.111 / −0.109 mm**，约目标的 5.5 倍。
- **基线与最危险假设**：基线=标称像素值直接转物理（无传播），会把标定界与定位界当成精确；主路线补区间传播。最危险假设是把“小数像素/拟合稳定”当作实物精度（image-geometry.md：亚像素 ≠ 物理精度，标定常主导）。
- **Q2 还需的证据（写为条件，不预填达标结论）**：
  1. 独立实物参考：经检定量块/标定件（证书可溯）走**同一管线**测同尺寸；
  2. 标定：1% 尺度界对应 10 mm 上 0.1 mm；要在 4–6 mm 边上支持 ±0.02 mm，尺度相对界需 ≲ 0.2%（标定像素距离误差 ≲ 0.4 px，或更长基准/多点标定）；
  3. 定位：边（两顶点合计）需 ≲ 0.4 px（每顶点 ≲ 0.2 px），且由重复提取的边缘重复性数据支撑，不能只引用给定界；
  4. 明确 ±0.02 mm 的对象（单边长/周长；重复度 vs 准确度）；
  5. 被忽略项（镜头畸变、共面/透视、边缘算法偏置、温度/机械形变）均需界定证据。
- **条件答案/备用**：拿不到实物参考时，只交付“按给定界传播的保证区间”（上文数值），物理准确度状态标 `unable-to-verify`，禁止写成达标；无概率模型，禁止“置信区间/显著性”等措辞。

## 3. 关键公式与实现约定
| 用途 | 公式 / 算法 | 边界与单位 |
|---|---|---|
| 尺度 | s = 10/D，D ∈ [198, 202] px | mm/px；区间含摄 |
| 周长 | P = Σ√((Δx)²+(Δy)²)（4 边，闭合） | px；禁端点距离 |
| 面积 | A = ½|Σ(xᵢyᵢ₊₁ − xᵢ₊₁yᵢ)| | px²；记录方向 |
| 物理换算 | L_mm = L_px·s；A_mm² = A_px²·s² | 独立最坏情况组合 |
| 定位 | 每顶点 (δx,δy) ∈ [−0.5,0.5]² | 边差一阶 ±1 px |
