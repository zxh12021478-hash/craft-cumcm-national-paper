# 给 Modex：两小时生产线调度

原题：工件相同且不可分割，两小时内加工，每小时最多10件，无跨小时或窗外生产。Q1需求20件；Q2仍20件、单位成本第一小时1元/第二小时0.1元；Q3改为12件。

**主路线**：两变量线性整数约束可直接消元，无须复杂算法。令 x1,x2 为各小时件数，x1+x2=D，x1,x2∈{0,…,10}。Q2/Q3最小化 C=x1+0.1x2=D−0.9x2，故取 x2=min(D,10)、x1=D−x2；可行条件为整数D且0≤D≤20。

**答案与依据**：Q1/Q2唯一可行调度均为(10,10)，Q2成本11元；价格改变成本但不改变被满载约束锁定的调度，不能为制造创新放宽产能。Q3为(2,10)，成本3元；x2≤10给出C≥12−0.9×10=3，下界取等。可报告的价值是这条决策边界，而非新算法。
