> 标签约定：**已执行**＝本包附带本机实际运行结果；**待验证**＝由 Modex 实现并回传证据。
> 题目边界（不得扩张）：两小时、每小时最多 10 件、不可跨小时加工、不可提前/延后到两小时之外、工件相同且不可分割。

## 2. 主路线、价值与备选

- **主路线（三问统一）：两变量整数线性规划/闭式贪心，按"便宜小时先用满"求解。**
  - 输入（产能 K=10、小时数 T=2、需求 D、成本 c1>c2）→ 约束代入 + 便宜小时饱和分配 → 调度表与成本 → 回代核查。
  - 基线＝贪心：先把最便宜小时填到产能上限，再填次便宜小时。本题规模下基线即最优，无需引入更强求解器或更复杂模型（不为创新改变题目）。
- **可检验的"改进/无须改进"依据（价格条件的作用边界）**：
  - 痛点：Q2 新增价差后，直觉是"都挪到便宜的第 2 小时"。
  - 机制与证伪：价差只在存在闲置产能时才能改变调度。D=20 时两小时总产能恰好等于需求（20=2K），需求等式与产能上界迫使 x1=x2=10，**任何正价差都无法改变调度**，只决定成本数值（11 元）。
  - 决策边界：当 D<2K（本题 Q3：D=12）时出现闲置，便宜小时先饱和才有调度作用；当 D=2K 时调度与价格无关。该边界由代入不等式直接证明，非数值巧合。
- **最危险假设**：把"至少完成 D 件"当作"恰好 D 件"。已执行枚举显示：成本严格为正时，≥D 的最优解仍恰为 D 件（多产只增成本），两种口径本题结论一致；若允许零/负成本（补贴）则需重新讨论。
- **备用路线及触发条件（触发才用，不主动扩张）**：
  1. 若题目扩展到 T>2 小时或小时产能/成本各异地异 → 同一 ILP（变量 xt、产能上界、需求等式、min Σctxt），可用标准库小规模枚举或 Modex 环境内求解器；闭式"按成本升序逐小时填满"对均匀小时成本仍最优。
  2. 若工件可区分/有工时差异 → 改为每件 0-1 指派变量（指派问题），本题不触发。
  3. 若允许跨小时加工 → 需引入连续性/批量变量，题意明确禁止，不采用。
- 不可行情形证书：D>20 时整数可行解集为空（需求 20 > 总产能 20 才不可行；D=20 恰可行且唯一）；Modex 若遇参数改动应先报不可行性而非硬造调度。

## 3. 关键公式与实现约定

| 用途 | 公式 | 变量/单位/边界 | 实现要点 |
|---|---|---|---|
| 产能与不可分 | x_t ∈ ℤ, 0 ≤ x_t ≤ 10, t=1,2 | 件；整数 | 每小时独立计数，禁止跨小时 |
| 需求 | x1+x2 = D（D=20/20/12） | 件 | 正成本下 ≥D 与 =D 最优等价（已枚举） |
| Q1 可行性 | 可行 iff D ≤ 2K=20；D=20 ⇒ x1=x2=10 | K=10 | 解唯一：(10,10) |
| Q2 成本 | min C = x1 + 0.1 x2 | 元 | x1=20−x2 ≥ 10（因 x2≤10），结合 x1≤10 ⇒ x1=10,x2=10，C=10×1+10×0.1=**11 元**，唯一 |
| Q3 成本与调度 | 便宜小时先满：x2=min(10,12)=10，x1=12−10=2 | 元 | C=2×1+10×0.1=**3 元** |
| Q3 最优性界 | x2≤10 ⇒ x1≥2；C=1.2+0.9 x1 ≥ 3 | x1=2 取等 | 交换论证：任一可行解若 x1>2，把一件从第 1 小时移到第 2 小时（x2<10 时尚有容量），成本降 0.9 元 |
| 通用闭式 | 按 c_t 升序逐小时填满 min(K, 剩余需求) | 本题 T=2 | 两小时均匀成本下严格最优；可用完整枚举交叉验证 |
