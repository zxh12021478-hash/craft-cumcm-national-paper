# APMCM 历史评阅原则 → 当前可执行质量检查

来源是 [2021 官方参赛规则第四节及摘要说明](https://www.apmcm.org/detail/2416)和[2021 章程第八条](https://www.apmcm.org/detail/2415)，不是当届未公开的细则。历史规则列出题意解读、假设论证、建模理由、有效模型、稳定性、优缺点/结论、准确完整摘要，并说明评判不设数字形式的分数。章程强调合理性、创造性与表述规范。以下是本 Skill 的工作检查，不是官方权重或获奖阈值。

## 从交接开始保留能让评阅者判断的证据

沿用现有 Q 覆盖表，在同一交接包里回答：

| 评阅关注 | 思路交接时交给 Modex | 初稿回来核查什么 |
|---|---|---|
| 题意及歧义 | 原题输出、关键解释及题面理由 | 有没有换问题、漏条件或用可选扩展替代必答 |
| 假设合理性 | 会改变答案的假设、量级/来源、失败信号 | 假设是否与数据/物理冲突，结论是否依赖未知参数 |
| 建模论证 | 结构机制为何适合本题，最简单可信基线 | 公式如何落到实际计算与题目输出，方法名称不算论证 |
| 有效求解 | 明确接口、约束、验收量和备用路线 | 直接答案、独立重算、可行性与最优性作用域 |
| 稳定性 | 最可能改变推荐的扰动/失配及最小检查 | 扰动是否传到最终方案，何时换方案；不能只展示平滑曲线 |
| 结论及取舍 | 什么决策值得推荐、代价和适用边界 | 比较同口径，局限是否具体影响使用，而非例行优缺点 |
| 摘要 | 每问所需结果证据及亮点 | 按 abstract-priority.md 重构答案、机制、比较和必要限制 |

不用为每格新增长报告。思路阶段尚未执行的验证列为 Modex 任务；不为提前取得所有证据而全量解题。优先把一条真正改变答案、可验证的结构贡献做扎实。附加算法、更多图表和更长论文本身不产生创造性。

## 评阅者能否迅速找到依据

每个主结论能沿“原题问什么 → 为什么这样建模 → 结果是什么 → 凭什么可信”定位正文/式/表。重要图表独立说明对象、坐标/单位、比较口径和结论；多彩图不能代替误差或方案价值。原题要求的完整大表可放合适位置，正文仍须给直接解释。

内部审查分为：影响必答结论的缺陷、证据不足、表达问题；重大缺陷不能靠平均分掩盖。历史规则接受不完整论文，因此“缺问”是本工作流的竞争力缺口，不能擅称官方取消资格。官方违规与内部质量未达标分别记录。先修对结论影响最大的缺口，再提升摘要和阅读体验；保全当前最好可用版本，避免最后时刻无验证换路线。

## 案例与概率边界

参考 exemplar-decisions.md，只迁移适用机制与验证方式，不移植往届数字、措辞或结论。奖级核验不认证每个科学主张；排版奖、创新奖入围与最终创新奖分别记录。[2025 年度赛后通知](https://www.apmcm.org/detail/2502)也把一等奖、创新奖申请和排版/编程奖区分开。

优秀论文是被筛选样本，没有未获奖对照和真实评审反馈，不能据此估计本队获奖概率。全体历史获奖比例同样不是本队条件概率。不设置“90%一等奖通过”标签，不把自评、脚本通过或 AI 审稿换算成概率。用户要求冲一等奖时，执行上述具体检查并报告真实缺口。
