# Modex 初稿回传单

用于定位审查材料，不是官方提交格式；先交接路线时不要求这些结果已经存在。

- 完整英文初稿源文件及可预览 PDF；图表源数据/绘图脚本。
- 可执行代码、依赖/版本、入口命令、必要输入、随机种子与实际运行记录。区分已执行和未执行；缺失材料直接说明。
- 机器可读结果：单位、场景、基线、主结果、检查指标和配置；标明模拟/实测/假设，不只返回截图。
- 按原交接包 Q 编号的覆盖表：

| 原题要求 ID | 正文位置与直接答案 | 代码/结果定位 | 已执行检查 | 未解决问题 |
|---|---|---|---|---|
| Q… |  |  |  |  |

- 主要创新：相对基线改变了什么、对照证据、适用范围；证伪后撤回的主张。
- 英文 Summary 及其主张的正文/结果定位，复用上述覆盖表与已有 claim ledger；每问直接答案、基线/比较口径、关键验证与限制。摘要证据缺失须标明，不能靠润色补齐。
- 偏离交接路线的地方及原因；修订版附变化文件、结果变化与未解决事项。

Skill 审查顺序：改变答案的错误/缺问/不可行方案 → 证据不足和不确定性 → 英文与版式。只给论文时可以审语言和内部逻辑，但缺少代码/结果的复现状态必须保留为未验证。
